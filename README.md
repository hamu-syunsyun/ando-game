# 安東先生から単位をもぎとれ！

文化祭の教室展示用のブラウザゲームです。科目は電気回路。安東先生は架空の人物です。

インストールもネット接続もいりません。`index.html` をブラウザ（Chrome か Edge 推奨）で開けば遊べます。

## ゲームモード

| モード | 時間 | 内容 |
| --- | --- | --- |
| 小テスト | 60秒 | オームの法則・合成抵抗・電力・分圧・単位などの4択。キーボードの 1〜4 でも答えられる |
| カラーコード | 60秒 | 抵抗の色の帯を読んで何 Ω か答える。色と数字の表は画面に出る |
| 配線パズル | 90秒 | ブレッドボード上の線をクリックで回して、＋5V から LED までつなぐ。進むほど盤面が広くなる |
| 期末試験 | 約2分 | 小テスト40秒 → カラーコード30秒 → 配線パズル60秒 の合計点で判定 |
| ボス戦（3D） | 3分 | 安東先生を3Dアクションで倒す。倒せば単位認定、早く倒すほど高得点 |

- 連続正解でコンボボーナス（最大 +100 点）
- 4択でまちがえると残り時間 −3秒、配線パズルのパスは −5秒
- 点数に応じて 秀・優・良・可・不可 がつき、可以上で「単位認定」
- モードごとに上位10位のランキングがあり、ランクインしたら名前を登録できる

## ボス戦（3D）の操作

| 操作 | キー |
| --- | --- |
| 移動 | W A S D（矢印キーでも可） |
| 視点 | マウス（最初に画面をクリックするとマウスが固定される。Esc で解除） |
| 通常攻撃 | 左クリック（押しっぱなしで3段コンボ）。マウスが使いにくいときは J キー |
| 元素スキル「放電」 | E（周囲に電撃。6秒ごと） |
| 元素爆発「V = I R」 | Q（ゲージ満タン時。ボスに雷を6連続で落とす） |
| 回避 | Shift か右クリック（スタミナを使う。回避中は無敵） |
| ジャンプ | Space（紫の衝撃波はジャンプでかわす） |

- 安東先生の攻撃は4種類。雷（赤い円）、抵抗器の弾幕、ジャンプからの衝撃波、突進（赤い帯）
- HPが半分を切ると「本気」になり、攻撃が速く多くなる
- 点数は「与えたダメージ（最大3000）」。倒すと「1000＋残り秒数×20＋残りHP」のボーナスが入る
- 3D表示には three.js（`vendor/three.min.js`、MIT ライセンス）を使っている。ネット接続は不要
- 3Dなので、古いPCだと動きが重くなることがある。当日使うPCで事前に一度遊んでおくこと

## 文化祭での置き方

1. PC で `index.html` を開く
2. タイトル画面の「全画面」ボタンか F11 で全画面にする
   - Chrome のキオスクモードを使うと、アドレスバーも消えて誤操作しにくい
     `chrome --kiosk "file:///C:/path/to/ando-game/index.html"`
3. 結果画面で60秒放置されると、名前は「ななし」で登録してタイトルに戻る

### 係の人向けの操作

- **M キー**：効果音のオン／オフ
- **タイトル画面で `resetrank` と打つ**：ランキングと受講者数を全部消す（確認あり）。本番前のテストプレイの記録を消すのに使う

### 注意

ランキングはその PC のブラウザの中（localStorage）に保存されます。

- 別のブラウザ、シークレットウィンドウ、別の PC では共有されない
- ブラウザの閲覧データを消すとランキングも消える
- 当日は毎回同じブラウザで同じファイルを開くこと

## 調整したいとき

- **成績の基準点**：`js/main.js` の `MODES` にある `grades: [秀, 優, 良, 可]`。試遊してみて、ちょうどいい難しさに合わせる
- **制限時間**：同じく `MODES` の `stages` の `time`（秒）
- **安東先生のセリフ**：`js/main.js` の `COMMENTS`（結果画面）と `TITLE_LINES`（タイトル画面）
- **知識問題の追加**：`js/quiz.js` の `CONCEPTS`。`a` の先頭が正解で、表示するときに順番はシャッフルされる
- **計算問題の追加**：`js/quiz.js` の `GEN` に関数を足すと自動で出題される
