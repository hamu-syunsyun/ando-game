# 先生たちから単位をもぎとれ！ ボス戦（Unity 版）

ブラウザ版の「ボス戦（3D）」を、Unity 6 で原神風のアクションとして作り直したものです。安東先生・菅原先生は架空の人物です。

3Dモデル・画像・音楽・効果音のファイルは1つも使っていません。キャラクターも曲も効果音も、ゲームを起動したときにスクリプトが計算で作ります。フォント（M PLUS 1p と Dela Gothic One、どちらも SIL Open Font License）だけ同梱しています。

## 開き方

1. Unity Hub に **Unity 6（6000.0 LTS）** を入れる。作成時の版は 6000.0.84f1。6000.0 系なら別の版でも開けるはず
2. Unity Hub の「追加 → ディスクから追加」で、このフォルダ（`unity/AndoBossBattle`）を選ぶ
3. 開くと自動で `Assets/AndoBoss/Scenes/BossBattle.unity` が作られて開く。▶（再生）を押せば遊べる
   - もしシーンが開かなかったら、メニューの **安東ボス戦 → シーンを作り直して開く**
   - 実は、どのシーンで ▶ を押しても自動でゲームが始まるようになっている

描画はビルトインレンダーパイプライン（URP・HDRP なし）です。自作のシェーダー（セル調・アウトライン・リムライト・空・攻撃予告）と自作のポストエフェクト（ブルーム・色収差・放射ブラー・ビネット）を使っています。

## 当日用に exe を作る

1. メニューの **File → Build Profiles**（Unity 6）で Windows を選ぶ
2. シーン一覧に `Assets/AndoBoss/Scenes/BossBattle.unity` が入っていることを確認して **Build**
3. できた exe を当日のPCにフォルダごとコピーする。全画面で起動する

先生とキャラの名前を、実在しない名前に置きかえた版も作れます。メニューの **安東ボス戦 → Windows用のexeを作る（実名なし版）** で `Builds/WindowsAnon/BossBattle.exe` ができます（ウィンドウの題名も「単位をもぎとれ ボス戦」になります）。

## 操作

戦闘の操作（通常攻撃・特技・奥義・回避・ジャンプ・ロックオン）は、タイトル画面の **O キー**（コントローラーは上のボタン：Y / △ / X）で開く **設定画面** で自由に変えられます。下の表は最初の設定（プリセット「標準」）です。

| 操作 | キー |
| --- | --- |
| 移動 | W A S D（矢印キーでも可） |
| 視点 | マウス（戦闘中に画面をクリックするとマウスが固定される） |
| 通常攻撃 | 左クリック / J（押しっぱなしで連続攻撃） |
| 特技 | E |
| 奥義 | Q（やる気ゲージ満タン時。カットインが入る） |
| 回避 | Shift / 右クリック / K（スタミナを使う。回避中は無敵） |
| ジャンプ | Space（紫の衝撃波はジャンプでかわす） |
| ロックオン切替 | Tab / ホイールクリック（最初はON。マウスを触らないと自動でボスを向く） |
| 光の演出の強さ | F2（オフ → 控えめ → 派手。最初は「控えめ」） |
| 画風の切り替え | F3（アニメ調 ⇔ リアル調。最初は「アニメ調」） |
| 一時停止 | Esc / P |
| 音のオン・オフ | M |
| 結果画面 | R でもう一度、T でタイトル |

光の強さと画風の設定はPCに保存されるので、次に起動したときもそのままです。

画面に出るボタンの表記（右下の特技・奥義のアイコン、左下の操作ヒント、タイトルの操作方法、キャラ選択のカードなど）は、最後に触ったのがキーボードかコントローラーかで自動で切りかわります。コントローラーは Xbox・PS・Switch の表記をつないだ機種に合わせます。

### 設定画面（O キー／上のボタン）

| 項目 | できること |
| --- | --- |
| 難易度 | やさしい・ふつう・むずかしい・鬼（先生を選ぶ画面の ↑↓ でも変えられる） |
| プリセット | 「標準」「キーボードだけ（ZXCV）」「原神風（コントローラー）」「肩ボタン（コントローラー）」と、自分で登録した「マイ設定1〜3」から選ぶ |
| 操作ごとの割り当て | 通常攻撃・特技・奥義・回避・ジャンプ・ロックオンに、キーボード・マウスを2つ、コントローラーのボタンを2つまで。決定を押してから、割り当てたいキー（ボタン）を押す |
| マイ設定に登録 | 今の割り当てを「マイ設定1〜3」に保存する |
| 初期設定にもどす | 「標準」にもどす |

- 同じキーがほかの操作に入っていたら、そちらからは外れます
- 移動（WASD・矢印キー・左スティック）、視点、決定・もどる・一時停止は変えられません（操作できなくならないように）
- 設定はPCに保存されます

### 難易度

| 難易度 | 受けるダメージ | 先生のHP | 自分の体力 | 自分の体力（ダブル） | 攻撃の間隔 | 点数 |
| --- | --- | --- | --- | --- | --- | --- |
| やさしい | 少なめ | 7割 | そのまま | そのまま | ゆっくり | ×0.7 |
| ふつう | ふつう | そのまま | 1.1倍 | 1.25倍 | ふつう | ×1.0 |
| むずかしい | 多め | 1.15倍 | 1.25倍 | 1.5倍 | せまめ | ×1.2 |
| 鬼 | 大 | 1.3倍 | 1.4倍 | 1.8倍 | 休みなし | ×1.5 |

自分の体力（キャラごとの体力にかける倍率）は、難易度を上げるほど増えます。ダブル（安東＋菅原）は2人ぶんの攻撃を受けるので、増え方が多めです。

### コントローラー（Xbox / PlayStation / Switch プロコン）

USB か Bluetooth でつなげばそのまま使えます（キーボードと同時に使ってもOK）。
Unity の新しい Input System パッケージを使うので、初めてプロジェクトを開いたときに自動でダウンロードされます。

ボタンは「位置」で決まっているので、ゲーム中はどのコントローラーでも同じ場所のボタンが同じ動きになります（左のボタンで攻撃、下のボタンでジャンプ、右のボタンで回避）。
Switch プロコンのときだけ、メニューの決定・戻るを Switch の決まり（A で決定、B で戻る）に合わせています。

| 操作 | Xbox | PlayStation | Switch プロコン |
| --- | --- | --- | --- |
| 移動 | 左スティック / 十字キー | 左スティック / 十字キー | 左スティック / 十字ボタン |
| 視点 | 右スティック | 右スティック | 右スティック |
| 通常攻撃 | X（押しっぱなしで連続） | □ | Y |
| ジャンプ | A | × | B |
| 回避 | B / RT | ○ / R2 | A / ZR |
| 決定（メニュー） | A | × | A |
| 戻る（メニュー） | B | ○ | B |
| 特技 | RB | R1 | R |
| 奥義 | Y / LB | △ / L1 | X / L |
| ロックオン切替 | 右スティック押しこみ | R3 | 右スティック押しこみ |
| 一時停止 | START（メニュー） | OPTIONS | ＋ |
| タイトルへ | ビュー | クリエイト（SHARE） | − |
| 結果画面でもう一度 | Y | △ | X |

Switch プロコンは Windows で使えます（USB でも Bluetooth でも可）。Steam を起動していると Steam がプロコンを横取りすることがあるので、うまく反応しないときは Steam を終了してください。

## キャラクター（4人）

| キャラ | 属性・武器 | 通常攻撃 | 特技（E） | 奥義（Q） |
| --- | --- | --- | --- | --- |
| ともき | 雷・片手剣（俊足） | 4段斬り | **レポート提出**：雷をまとったレポートを投げる。刺さるとバババババッと10連ヒットし、1発ごとに雷が落ちる → 「提出完了！！」で雷の柱が囲む | **一夜漬け・雷光乱舞**：夜が来て、ボスに飛びこみ14連斬り（斬るたびに落雷）→ 〆切斬りで雷の輪が広がる |
| 杉山くん | 炎・拳（ラグビー部） | 炎の拳で3段 | **炎のロングパス**：炎をまとったラグビーボールを投げて爆発 | **ラグビー部タックル**：炎をまとってボスに3回突っこみ、最後に全力タックル |
| やましょう | 風・弓（最強・ねむい） | 「ねみー」と言いながら弓を引いて矢を撃つ（4射目は3本） | **二度寝アロー**：空に矢を放つと、少しして矢の雨が降る | **寝ぼけ乱れ撃ち**：寝ぼけたまま弓を引きまくって矢を22連射 |
| らいと | 氷・槍（自称・数学の神） | 槍の5段突き（3段目は薙ぎ払い、最後は回転突き） | **証明終了（氷塊落とし）**：巨大な氷の塊をボスの真上から落とす（1発） | **数学の神・絶対零度の証明**：ボスを凍らせて16連突き → 天から氷の大槍「証明完了！！」。そのあと6秒間、先生は「証明済み」で受けるダメージ1.5倍 |

- 先生を選んだあとの画面でキャラを選ぶ（← → か 1〜4、Enter で決定）。**交代はできない**ので、選んだキャラで最後まで戦う
- 体力：ともき・杉山くん 1500、らいと 1300、やましょう 1000。攻撃力：杉山くん（拳）がいちばん高く、次にらいと・ともき
- **ともきの能力「俊足」**：足の速さ1.4倍、スタミナ1.6倍（回避をたくさん使える）
- **リーチ**：弓（やましょう）以外は攻撃が届く距離が長い。振るたびに剣圧（光の斬撃）が前に出るので、届く範囲が見える
- **らいとの能力「天才」**：会心率がいつも10%アップ。セリフは「ぼくそんなんじゃないよ〜」（戦闘開始）、「ぼくてんさいだから！」（ジャスト回避・攻撃中）、「ぼくは数学の神だよ！」（奥義）、「おまえふざけんなよぉぉぉ」（攻撃を受けたとき）、「えいじぃ〜」（HPが減ったとき）
- **氷の属性コンボ**：氷＋雷＝超電導、氷＋炎＝融解（ダメージ1.8倍）、氷＋風＝吹雪
- **杉山くんの能力**：特技を当てると、ボスの防御力が8秒間下がる（受けるダメージ1.3倍）
- **やましょうの能力「留年」**：1回やられても、HP半分で生き返り、極太の矢を2本撃ち返す（1戦に1回。右の「留年×1」が残り回数）
- スタミナは150。回避1回で20使う（1秒に55回復）
- **全員共通**：攻撃を受けたあと1.1秒は無敵、回避の無敵は0.28秒（ジャスト回避の判定は0.1秒）。やる気は1秒に0.6ずつ自然にたまる（開始時40）

## 安東先生（架空の人物・セリフは秋田弁）

- **雷**（赤い円）、**抵抗器の弾幕**、**ジャンプからの衝撃波**（跳んでよける）
- **いやいや攻撃**：首を横にぶんぶん振りながら、ドタバタ跳ね回る。着地点の赤い円に注意
- **トランス攻撃**：変圧器を投げてくる。着地や磁気の波に当たると5秒間「鈍足」（移動が半分の速さ）
- **必殺「三相交流」**：120度ずつずれた赤・黄・青の3枚の巨大な正弦波の「壁」（高さ7m・長さ46m）が一気に伸びる。波は横に流れていくので、3枚のすき間にもぐりこんでついていく。ジャンプでは越えられない。発生は約0.5秒（床に光る線が出たらすぐ）。本気モードでは波が大きく速くなる
- 本気モード（HP半分以下）で増える攻撃：**オームの法則ビーム**（薙ぎ払い）、**キルヒホッフの渦**（らせん弾）
- 「おれ、もう知らねがらな！」（本気モード）、「練習問題と同じでねが！」（攻撃が当たったとき）などのセリフ

## 菅原先生（架空の人物・英語担当・「死神」「北の破壊神」）

- タイトルのあと、**たおす先生を選ぶ画面**で安東先生・菅原先生・ダブル（超ハード）を選べる（← → か 1・2・3）。ベストスコアはそれぞれ別
- 見た目：白髪、細長い顔、メガネなし。背が高くて細身
- **カウント制**：菅原先生の攻撃に当たると「カウント」が1つ（「もらってみる？？」の玉は2つ）つく。**カウント5で単位消滅（即アウト）**。画面左上に5つの枠
- **ジャスト回避でカウントを1つ取り消せる**（「……今のは、ノーカウント。」）
- 攻撃：赤ペンの×印の弾幕、赤ペンの大鎌の薙ぎ払い、空から降る英単語の文字、**英単語の壁**（光るすき間を通り抜ける）、「(カウントを)もらってみる？？」の追尾玉、**答案返却**（×のついた答案がブーメランのように戻ってくる）、**リスニングテスト**（音の輪が何重にも広がる。ジャンプでよける）、**赤ペン添削**（アリーナに引かれた赤い線にそって爆発）
- 本気モード（HP半分以下）で**必殺「北の破壊神」**：「正」の字（カウント5）の5画が、高さ9mの巨大な壁になって次々に落ちてくる。画と画のすき間にもぐりこんでよけ、最後に字の中心から出る衝撃波はジャンプでよける。当たるとカウント
- 声はかすかすのささやき声（プログラムで合成）。字幕はかすれた筆文字フォント（Yuji Boku）で、文字がチラチラかすれる
- 名言「(カウントを)もらってみる？？」「英検準2級も取れない人は……ピーーーーッ（自主規制）」など

## 超ハード：ダブル補講（安東先生＋菅原先生）

- 2人の先生が同時に襲ってくる。攻撃はプレイヤーに近いほうの先生に当たる（上のHPバーが今の相手、その下の小さいバーがもう1人）
- 1人あたりのHPは11000、制限時間は5分。カウント5で単位消滅もそのまま
- 1人倒すと、少しして残った先生が本気モードになる
- 撃破ボーナスは3000。成績の基準は通常より8000点高い

## 遊びの中身

- **ジャスト回避**：攻撃が当たる直前（回避の出だし0.1秒）にかわすと、スローモーション＋5秒間会心率アップ。判定は厳しめ
- **エナジードリンク**：20秒前後ごとに空から落ちてくる（緑の輪が目印）。拾うとHPが250回復
- **ノックバック**：攻撃を受けると吹き飛ばされて、少しの間動けない
- **ブレイク**：HPバーの下の「理論武装」ゲージを削りきると、5秒間ボスが気絶してダメージ1.3倍
- **やる気**：攻撃を当てると光の玉が出て、拾うと奥義のゲージがたまる（控えのキャラも少したまる）
- **ボスのHP**は16000、制限時間は4分。ボスの攻撃は強め・間隔は短め（`Scripts/Game.cs` の `EnemyDmgMul`・`PlayerDmgMul` で調整できる）
- **点数**：与えたダメージ（最大16000）＋撃破ボーナス1000＋残り秒数×20＋残りHP＋ジャスト回避×100＋最大コンボ×5
- **成績**：倒せば「可」以上で単位認定（秀 19500・優 18700・良 18000 以上）。倒せなければ「不可」
- ベストスコアはPCに保存される。消したいときはメニューの **安東ボス戦 → ベストスコアを消す**
