# 安東先生から単位をもぎとれ！ ボス戦（Unity 版）

ブラウザ版の「ボス戦（3D）」を、Unity 6 で原神風のアクションとして作り直したものです。安東先生は架空の人物です。

3Dモデル・画像・音楽・効果音のファイルは1つも使っていません。キャラクターも曲も効果音も、ゲームを起動したときにスクリプトが計算で作ります。フォント（M PLUS 1p と Dela Gothic One、どちらも SIL Open Font License）だけ同梱しています。

## 開き方

1. Unity Hub に **Unity 6（6000.0 LTS）** を入れる。作成時の版は 6000.0.84f1。6000.0 系なら別の版でも開けるはず
2. Unity Hub の「追加 → ディスクから追加」で、このフォルダ（`unity/AndoBossBattle`）を選ぶ
3. 開くと自動で `Assets/AndoBoss/Scenes/BossBattle.unity` が作られて開く。▶（再生）を押せば遊べる
   - もしシーンが開かなかったら、メニューの **安東ボス戦 → シーンを作り直して開く**
   - 実は、どのシーンで ▶ を押しても自動でゲームが始まるようになっている

描画はビルトインレンダーパイプライン（URP・HDRP なし）です。自作のシェーダー（セル調・アウトライン・リムライト・空・攻撃予告）と自作のポストエフェクト（ブルーム・色収差・放射ブラー・ビネット）を使っています。

## 当日用に exe を作る

1. メニューの **File → Build Profiles**（Unity 6）で Windows を選ぶ
2. シーン一覧に `Assets/AndoBoss/Scenes/BossBattle.unity` が入っていることを確認して **Build**
3. できた exe を当日のPCにフォルダごとコピーする。全画面で起動する

## 実名なし版

先生とキャラの名前を、実在しない名前に置きかえた版も作れます。メニューの **安東ボス戦 → Windows用のexeを作る（実名なし版）** で `Builds/WindowsAnon/BossBattle.exe` ができます（ウィンドウの題名も「単位をもぎとれ ボス戦」になります）。

| 元の名前 | 実名なし版 |
| --- | --- |
| 安東先生 | ボルト先生 |
| 菅原先生 | グリム先生 |
| ともき | らいと |
| 杉山くん | ほむらくん |
| やましょう | ねむお |

名前は `Scripts/Names.cs` の表を書きかえると変えられます。ゲームの中身は通常版と同じです。

## キャラクター（3人とも架空の人物）

| キャラ | 属性・武器 | 通常攻撃 | 特技（E） | 奥義（Q） |
| --- | --- | --- | --- | --- |
| ともき | 雷・片手剣 | 4段斬り | **レポート提出**：雷をまとったレポートを投げる。ボスに刺さるとバババババッと10連ヒット | **一夜漬け・雷光乱舞**：夜が来て、ボスに飛びこみ14連斬り → 〆切斬り |
| 杉山くん | 炎・拳（ラグビー部） | 炎の拳で3段 | **炎のロングパス**：炎をまとったラグビーボールを投げて爆発 | **ラグビー部タックル**：炎をまとってボスに3回突っこみ、最後に全力タックル |
| やましょう | 風・弓（最強・ねむい） | 「ねみー」と言いながら矢を撃つ（4射目は3本） | **二度寝アロー**：空に矢を放つと、少しして矢の雨が降る | **寝ぼけ乱れ撃ち**：寝ぼけたまま矢を22連射 |

- タイトルのあとの選択画面でキャラを選ぶ（← → か 1・2・3、Enter で決定）。**交代はできない**ので、選んだキャラで最後まで戦う
- 体力：ともき・杉山くん 1500、やましょう 1000。攻撃力：杉山くん（拳）がいちばん高く、次にともき
- **杉山くんの能力**：特技を当てると、ボスの防御力が8秒間下がる（受けるダメージ1.3倍）
- **やましょうの能力「留年」**：1回やられても、HP半分で生き返り、極太の矢を2本撃ち返す（1戦に1回。右の「留年×1」が残り回数）
- スタミナは150

## 安東先生（架空の人物・セリフは秋田弁）

- **雷**（赤い円）、**抵抗器の弾幕**、**ジャンプからの衝撃波**（跳んでよける）
- **いやいや攻撃**：首を横にぶんぶん振りながら、ドタバタ跳ね回る。着地点の赤い円に注意
- **トランス攻撃**：変圧器を投げてくる。着地や磁気の波に当たると5秒間「鈍足」（移動が半分の速さ）
- **必殺「三相交流」**：120度ずつずれた赤・黄・青の3本の正弦波を撃ち出す。本気モードでは3方向
- 本気モード（HP半分以下）で増える攻撃：**オームの法則ビーム**（薙ぎ払い）、**キルヒホッフの渦**（らせん弾）
- 「おれ、もう知らねがらな！」（本気モード）、「練習問題と同じでねが！」（攻撃が当たったとき）などのセリフ

## 菅原先生（架空の人物・英語担当・「死神」「北の破壊神」）

- タイトルのあと、**たおす先生を選ぶ画面**で安東先生・菅原先生・ダブル（超ハード）を選べる（← → か 1・2・3）。ベストスコアはそれぞれ別
- 見た目：白髪、細長い顔、メガネなし。背が高くて細身
- **カウント制**：菅原先生の攻撃に当たると「カウント」が1つ（「もらってみる？？」の玉は2つ）つく。**カウント5で単位消滅（即アウト）**。画面左上に5つの枠
- **ジャスト回避でカウントを1つ取り消せる**（「……今のは、ノーカウント。」）
- 攻撃：赤ペンの×印の弾幕、赤ペンの大鎌の薙ぎ払い、空から降る英単語の文字、**英単語の壁**（光るすき間を通り抜ける）、「(カウントを)もらってみる？？」の追尾玉
- 本気モード（HP半分以下）で**北の破壊神**：破壊の柱が5本落ちてくる
- 声はかすかすのささやき声（プログラムで合成）。字幕はかすれた筆文字フォント（Yuji Boku）で、文字がチラチラかすれる
- 名言「(カウントを)もらってみる？？」「英検準2級も取れない人は……ピーーーーッ（自主規制）」など

## 超ハード：ダブル補講（安東先生＋菅原先生）

- 2人の先生が同時に襲ってくる。攻撃はプレイヤーに近いほうの先生に当たる（上のHPバーが今の相手、その下の小さいバーがもう1人）
- 1人あたりのHPは11000、制限時間は4分30秒。カウント5で単位消滅もそのまま
- 1人倒すと、少しして残った先生が本気モードになる
- 撃破ボーナスは3000。成績の基準は通常より8000点高い

## 遊びの中身

- **ジャスト回避**：攻撃が当たる直前（回避の出だし0.1秒）にかわすと、スローモーション＋5秒間会心率アップ。判定は厳しめ
- **エナジードリンク**：20秒前後ごとに空から落ちてくる（緑の輪が目印）。拾うとHPが250回復
- **ノックバック**：攻撃を受けると吹き飛ばされて、少しの間動けない
- **ブレイク**：HPバーの下の「理論武装」ゲージを削りきると、5秒間ボスが気絶してダメージ1.3倍
- **やる気**：攻撃を当てると光の玉が出て、拾うと奥義のゲージがたまる（控えのキャラも少したまる）
- **ボスのHP**は16000、制限時間は3分30秒。ボスの攻撃は強め・間隔は短め（`Scripts/Game.cs` の `EnemyDmgMul`・`PlayerDmgMul` で調整できる）
- **点数**：与えたダメージ（最大16000）＋撃破ボーナス1000＋残り秒数×20＋残りHP＋ジャスト回避×100＋最大コンボ×5
- **成績**：倒せば「可」以上で単位認定（秀 19500・優 18700・良 18000 以上）。倒せなければ「不可」
- ベストスコアはPCに保存される。消したいときはメニューの **安東ボス戦 → ベストスコアを消す**

## 調整したいとき

| 変えたいもの | 場所 |
| --- | --- |
| 制限時間 | `Scripts/Game.cs` の `TimeLimit` |
| キャラの攻撃力・スキル名 | `Scripts/Party.cs`（スキル・属性爆発の中身は `Scripts/Skills.cs`） |
| 成績の基準点・点数の計算 | `Scripts/Game.cs` の `ShowResult` |
| ボスのHP・理論武装ゲージ | `Scripts/Boss.cs` の `MaxHp`・`MaxTough` |
| ボスの攻撃・セリフ | 安東先生は `Scripts/Boss.cs`、菅原先生は `Scripts/BossSuga.cs` の `Atk○○` と `SugaOne`・`SugaLines` |
| カウントの上限 | `Scripts/Game.cs` の `MaxCount` |
| キャラの動き | `Scripts/Player.cs` の `Tick` |
| 曲（メロディ・コード・テンポ） | `Scripts/Music.cs` の `Melody`・`Prog`・`BPM` |
| 効果音 | `Scripts/Sfx.cs` の `BuildData` |
| 画面の色味・光り具合 | `Scripts/PostFX.cs` の `BloomIntensity`・`Exposure` など、エフェクト全体の明るさは `Scripts/Mat.cs` の `FxGain` |

## ファイル構成

```
Assets/AndoBoss/
  Scripts/
    Game.cs        進行（タイトル→登場→戦闘→決着→結果）・ダメージ計算・演出のきっかけ
    Party.cs       3人のキャラ設定・属性コンボ
    Player.cs      操作キャラ（見た目・操作・コンボ・回避）
    Skills.cs      3人の特技と奥義
    Boss.cs        ボスの共通部分と安東先生（見た目・8種類の攻撃・第2形態・ブレイク）
    BossSuga.cs    菅原先生（見た目・カウント攻撃・英単語の壁・北の破壊神・セリフ）
    CameraRig.cs   三人称カメラ・ロックオン・画面の揺れ・演出カメラ
    Hud.cs         UI（HPバー・スキル・コンボ・ダメージ数字・カットイン・タイトル・結果）
    Fx.cs          エフェクト（火花・稲妻・輪・紙吹雪）とヒットストップ・スロー
    World.cs       アリーナ・空・景色
    PostFX.cs      ポストエフェクト
    Music.cs       曲の自動作曲・演奏（160BPM・ニ短調・5パート）
    Sfx.cs         効果音の合成（45種類）
    Synth.cs       音づくりの道具
    Mat.cs         マテリアル・メッシュ・テクスチャづくり
    GameInput.cs   キーボード・マウス入力
    GamePadInput.cs コントローラー入力（Xbox / PS、新 Input System）
    ShotTour.cs    動作確認用のスクリーンショット自動撮影（起動引数 -andoShots のときだけ動く）
  Editor/AndoBossSetup.cs   初回にシーンを作る・メニュー
  Resources/Shaders/        自作シェーダー
  Resources/Fonts/          フォントとライセンス（菅原先生の字幕は Yuji Boku、SIL OFL）
```
